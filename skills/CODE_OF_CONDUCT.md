# Código de Conduta

## Nosso compromisso

Queremos um ambiente acolhedor, respeitoso e livre de assédio para todas as pessoas que participam do projeto, independentemente de idade, deficiência, etnia, gênero, identidade, nível de experiência, nacionalidade, aparência, religião ou orientação sexual.

## Comportamentos esperados

- Usar linguagem acolhedora e inclusiva.
- Respeitar opiniões e experiências diferentes.
- Aceitar críticas construtivas com maturidade.
- Focar no que é melhor para a comunidade e para o projeto.

## Comportamentos inaceitáveis

- Linguagem ou imagens sexualizadas, e atenção sexual indesejada.
- Insultos, ataques pessoais, trolling ou comentários depreciativos.
- Assédio público ou privado.
- Divulgar informações privadas de outras pessoas sem permissão (inclusive dados de alunos, como RA, e-mail ou foto).
- Qualquer conduta considerada inadequada em um ambiente profissional.

## Aplicação

Casos de comportamento inaceitável podem ser relatados abrindo uma *Security Advisory* privada ou contatando os mantenedores pelo GitHub (<https://github.com/Adangomes/UNICHAMADA>). Todas as denúncias serão analisadas com discrição e imparcialidade.

Este código é adaptado do [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), versão 2.1.
