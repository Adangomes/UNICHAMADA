# Código de Conduta do Contribuinte

## Nosso Compromisso
Como participantes e mantenedores deste projeto, comprometemo-nos a proporcionar um ambiente livre de assédio para todos, independentemente de idade, deficiência, raça, sexo, identidade de gênero, religião ou orientação sexual.

## Nossos Padrões
Exemplos de comportamento que contribuem para criar um ambiente positivo incluem:
- O uso de linguagem acolhedora e inclusiva.
- Respeito a diferentes pontos de vista e experiências.
- Aceitação construtiva de críticas.
