# Política de Segurança

## Versões Suportadas
Atualmente, a versão 2.0.0 é a única com suporte ativo a correções de segurança.

## Reportar uma Vulnerabilidade
Se encontrar alguma falha de segurança relacionada à validação de geolocalização, bypass de tokens de chamada ou exposição de dados no Supabase, por favor, entre em contato diretamente através dos canais do mantenedor do projeto em vez de abrir issues públicas.
